# 材料实验工作台

根据《材料基础实验》2026-09-14 讲义编写的本地网站：十项实验辅导与原理推导、十个教学模拟、30 道讲义讨论题的参考解答、每项实验三篇文献，以及实验数据与报告写作工作区。代码仓库公开供审阅，网站只监听本机 127.0.0.1，没有部署 GitHub Pages 或任何云站点。

## 启动

Windows 需要 Python 3.10+ 与系统宋体、黑体、Times New Roman。本机环境已具备依赖；其他机器首次运行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe server.py
```

打开 <http://127.0.0.1:5188>。也可双击 `启动网站.cmd`（启动隐藏的本地服务并打开浏览器）。端口可通过 `LAB_PORT` 环境变量修改。没有开机自启动；重新启动计算机后需重新运行启动文件。前台运行时 Ctrl+C 停止服务；启动脚本的后台服务可通过任务管理器结束对应的 Python 进程。

## 使用流程

1. 选择实验，阅读推导、实验路线与讨论题，下载过程简述 PDF。
2. 进入交互模拟，调整参数、导出 CSV 或 PNG/SVG。模拟数据转入写作工作区后会明确标记为教学模拟。
3. 在论文创建中填写日期、姓名、学号和组号。表格可选：导入自己的 CSV / XLSX、编辑表格，或直接上传 PDF/PNG/SVG 实验数据图；单位在模板列名中。可选择计算参数并导出数据图。FTIR 默认 CSV 纵轴为透射率百分数，DSC 默认 W/g 且吸热向上，热分析每次只导入一个升温段。
4. 上传个人过程描述 PDF（本地提取文字）或直接填写实际步骤；图表为可选；只有数据图也能创建报告，请补充“数据图说明”。过程扫描 PDF 目前不提供 OCR，可手动填写。
5. 点击“创建本地报告框架”可离线获得讨论题与计算结果，但分析、结论和文内引用仍需自己补全。使用 ChatGPT：复制资料包后打开 ChatGPT 粘贴，或下载提示词，再把返回的正文粘贴到编辑器。
6. 使用 DeepSeek：在页面输入 Key（仅当次请求使用、不持久化），或启动服务前设置环境变量 `DEEPSEEK_API_KEY`。先预览 AI 资料包；每次明确勾选同意后，点击生成会把去标识的数据、过程文字、图题和文献资料发送到 DeepSeek API。姓名学号等信息栏不发送，自动隐去不保证识别全部私密内容。可选图像只加入本地 PDF。模型默认 `deepseek-flash`，可按 [官方文档](https://api-docs.deepseek.com/) 修改。需要有效 Key 和余额，未配置 Key 时不会请求模型。
7. 核对全部讨论题、真实数据解释以及至少三篇相关论文的文内引用，编辑正文后导出 PDF。格式为 A4、四边 2.5 cm、中文宋体 12 pt、英文/数字 Times New Roman 12 pt、标题黑体 12 pt、1.5 倍行距、正文首行缩进 2 字、两端对齐；含附录一的六项信息。图下放图题。报告超过六页时拒绝导出，不截断、不缩小字号。

## 数据与来源

新草稿只在当前页面内存中，不自动写入浏览器或服务器。关闭/刷新前请输入 12–128 字符密码，使用左侧“加密备份当前实验”下载 `.mlab` 文件；恢复时先输入相同密码再选择文件。密码不会保存或传给服务器，遗忘无法恢复。旧版 JSON 仍可导入；旧浏览器缓存会提示备份后清除，不静默丢弃。

API Key 不进入白名单项目、备份或日志，输入在生成请求后清空。图片导入移除 EXIF 等文件元数据，图片上的可见个人信息需自己裁剪。PDF/CSV 导出仍是普通文件，应妥善保管。默认 PDF 文件名为 `实验3_报告.pdf`；需要课程格式时勾选“在 PDF 文件名中加入组号、姓名和学号”，例如 `实验3_07组_张三_20260001.pdf`（虚构示例）。本地 PDF 信息栏保留课程要求的身份资料。

公开仓库不含原讲义、个人数据、报告、备份、系统字体、环境配置或日志；本地排版所需的 MIT 许可 KaTeX 字体随代码附带。上传采用显式文件清单。隐私默认设置、数据流、解析限制和使用边界见 [SECURITY.md](SECURITY.md)。

`data/curriculum.json` 为整理后的讲义辅导内容。课程附录1–2来自讲义 PDF 第3–4页；十个实验及页码已标注。`build_content.py` 为初次整理脚本，需要仓库父目录中的外部 `lecture.txt`，日常启动不需要它。

`data/references.json` 包含30条引用、28篇独立论文，每项实验3篇。题录经出版社、DOI或原文核对，中文摘要为转述。access=abstract 表示读取摘要，fulltext 表示读取可访问的原文；不能把摘要阅读表述为完整全文阅读。论文生成使用固定已核验来源，模型不自行虚构参考文献；要开展新的专题研究，应自行扩充并核对来源。

## 计算与边界

BET 可调整拟合窗口，显示 nₘ、C、面积和一致性警示；默认 N₂ 截面积 0.162 nm²，STP 为0℃/1atm。高 R² 不保证模型适用。XRD 使用手动峰宽与高斯仪器展宽校正，不能自动完成分峰、结晶度或物相数据库鉴定。DSC 使用端点线性基线积分；TMA 为指定窗口线性拟合。光弹性计算主应力差和应力差变换，需要额外边界条件才能分离应力。

霍尔采用带符号四态反对称化和范德堡原始关系数值求解，单位统一 SI；与讲义中的绝对值平均和部分不一致的公式有明确区别。电压极性须自己核对，单载流子浓度假设霍尔因子1。四探针分别处理无限薄层与半无穷厚体，统一采用乘法修正 k；讲义未提供几何修正表，网站不补造，也不会自动选择有限尺寸修正。

模拟全部为简化模型，其中 MOF 晶化及聚合物谱形为定性示意，不能代替仪器测量。实测数据是否真实、样品组成、操作偏差及实验结论需要报告作者核验。

## Excel 数据导入

论文创建支持 `.csv` 与 `.xlsx` 上传（最多 8 MB）。单个可见工作表自动导入；多个工作表先选择，再点击“导入所选工作表”。首个非空行是表头，列名沿用空白 CSV 模板，可调整列顺序；只保留该实验需要的列，忽略空白行。每个工作表限 10,001 行（含表头）、64 列，每格 256 字符。

Excel 只读取单元格数值/文字，不导入格式、合并表头、图表或批注。公式使用 Excel 已保存的计算结果；没有缓存或包含错误时提示修正，不计算公式。请先在 Excel/WPS 中重新计算并保存，或粘贴为数值。旧 `.xls`、宏、嵌入对象和外部工作簿链接不支持；请另存为无宏 `.xlsx`。上传文件在本机受限子进程中解析，不保存原件、不发送到模型或 GitHub。


## 公式排版

十个实验的 60 条原理公式使用 `data/formulas.json` 中与原文对应的 LaTeX 排版，原理与计算模型不变。网页使用随代码附带的 KaTeX 0.19.0 与字体，无 CDN 请求。数学标签用英文（如 `sample`、`theory`），变量的中文解释保留在原理正文中。

报告正文支持行内 `\(n\lambda=2d\sin\theta\)` 与独立 `\[D=\frac{K\lambda}{\beta\cos\theta}\]`，也接受 `$...$` 与 `$$...$$`。展开“正文排版与公式预览”查看编辑效果；这不是最终 PDF 分页预览。

PDF 使用本地 Matplotlib MathText 在独立进程中生成 240 dpi 公式图，不执行完整 TeX。支持常用分式、上下标、根号、积分等；不支持矩阵环境、自定义宏、文件或链接命令，公式变量标签请用英文。每份文档最多 64 条公式、每条 512 字符，括号嵌套最多 16 层。网页和 PDF 的支持范围不同：网页语法错误保留原文，PDF 语法错误或超宽公式明确拒绝导出，需修改后重试。公式按 12 pt 排版，过宽时不缩小或裁切；高公式相应增加行高。PDF 中公式为嵌入图片，不能作为可搜索的公式文字提取；原始 LaTeX 保留在正文、Markdown 和加密备份中。


## 仅提供数据图写作

数值表格不是创建报告或 AI 资料包的必填项。可以点击实验数据区的“导入实验数据图”，或下方“实验图表 / 添加图表”，上传 PDF、PNG、SVG（兼容 JPEG）。PDF 限 8 MB，PNG/JPEG 限 4 MB，SVG 限 2 MB。PDF 每页作为一张图，与其他图表合计最多 5 张；超过剩余数量时整份 PDF 拒绝导入，不截断页数。

PDF/SVG 在无凭据、15 秒超时的本地子进程中转为静态 PNG，长边至多约 1600 像素、总像素不超过 200 万。预览、报告与加密备份保存规范化 PNG，不保存原文件的脚本、链接、附件或元数据；原件需要自己保管，矢量图在报告中成为位图。请核对字体、细线和坐标刻度的转换效果。

在“数据图说明”中记录图号、坐标轴、单位、测量条件、本人核实的数值与趋势。没有表格时不自动读图、提取坐标或拟合，框架与 AI 提示词明确区分文字描述和已核验数值，缺失定量结果保留待补充。DeepSeek 只接收去标识的图题与文字说明，不接收图片；ChatGPT 用户可自行附上已检查的图。说明与规范化图片一起进入加密备份，旧版项目仍可恢复。

自动计算、拟合和绘制数值曲线仍需数值表格；已经输入但格式错误或不完整的表格需要修正。报告 PDF 的信息栏、讨论题、至少三篇文献和最多六页要求保持不变。


## 数据图说明 PDF 原件

“数据图说明 / 导入说明 PDF”支持 8 MB、1–20 页的无密码 PDF。原始文件逐字节保留在当前实验的页面内存和加密备份中，可点击“下载原始 PDF”。此入口与将数据图 PDF 转为 PNG 的图表入口独立。不会把说明 PDF 转为图片或将其替换为提取文字；不在网页内执行或内嵌原 PDF。

说明为空时自动填入可提取文字，已有说明保留，可点击“追加提取文字”后自行核对。扫描件、过短或超过 18000 字符的文字不会阻止保留有效原件，可手动填写简要说明。移除原件不会清空文字。刷新前请加密备份，恢复会重新验证 PDF，文件名不保存，下载使用通用实验编号。AI 资料包只包含去标识文字，不含 PDF 文件和元数据；正文 PDF 仍按课程格式生成，不自动合并说明原件。

加密备份的明文容量上限为 40 MB，恢复文件上限 55 MB，以容纳说明 PDF 和图表；加密算法、密码要求和旧版备份兼容性保持不变。原件包含的元数据也原样保留，只供本地保存，不上传公开仓库。
